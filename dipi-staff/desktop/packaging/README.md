# Steam Deck desktop launcher

The file you want on the **Steam Deck** (Desktop Mode) is:

**`~/Desktop/dipi-staff.desktop`**

That path is `/home/deck/Desktop/dipi-staff.desktop` on the Deck. It is **not** created on macOS, and it is **not** named `dpstaff.desktop`.

| File | Where it lives |
|---|---|
| `dipi-staff.desktop` | Template in this folder; installed to the Deck Desktop |
| `install-on-steam-deck.sh` | Run **on the Steam Deck** after you copy the bundle |
| `make-steam-deck-bundle.sh` | Run on a Linux box to pack `desktop/dist/DIPI-Staff-SteamDeck/` |

See `docs/STEAM-DECK.md`.
